# 🏦 FinCore – Secure Digital Banking Platform

**Infosys Virtual Internship Project**

FinCore is a full-stack digital banking application developed as part of the **Infosys Virtual Internship**. The application provides a centralized platform for managing customers, bank accounts, transactions, reports, and customer loans through role-based workflows.

### 🚀 Key Features

* 🔐 **Role-Based Access** – Separate Admin and Customer workflows
* 👤 **Customer Management** – Registration, approval, editing, and reports
* 🏦 **Account Management** – Account creation, details, balance, and reports
* 💸 **Transaction Management** – Transaction processing and history
* 💰 **Loan Management** – Customer loan application and tracking
* 📊 **Reports** – Customer, account, and transaction reports

### 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, React Router, Axios, Bootstrap
**Backend:** Java, Spring Boot, REST APIs, Hibernate/JPA
**Database:** MySQL
**Tools:** Git, GitHub, VS Code, Eclipse, Postman

### 🏗️ Architecture

```text
React.js Frontend
       ↓
   REST APIs
       ↓
Spring Boot Backend
       ↓
    MySQL DB
```

### 🎯 Objective

To develop a secure, scalable, and user-friendly digital banking platform that simplifies core banking operations and provides an organized workflow for both administrators and customers.
